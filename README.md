# 🧠 Projeto 4 - Revisão para P1 DWIII

Este repositório contém a resolução de quatro exercícios práticos da disciplina de Desenvolvimento Web III (DWIII) da FATEC Diadema, com foco em fundamentos de back-end utilizando Node.js.

## 🛠️ Tecnologias Utilizadas

*   **Back-end:** Node.js (Módulos nativos: `fs`, `http`, `url`, `path`)
*   **Front-end:** HTML5, CSS3, JavaScript (Fetch API)
*   **Controle de Versão:** Git & GitHub

## 📚 Conteúdo Estudado / Exercícios

| Exercício | Descrição / Tópicos | Link da Pasta |
| :--- | :--- | :--- |
| **01. Configuração** | Leitura assíncrona de arquivos `.json` usando o módulo nativo `fs` para extrair dados de configuração. | [Acessar](./ex01) |
| **02. Sistema de Logs** | Manipulação de arquivos de texto (`log.txt`) para registrar acessos (operações de *append* e criação automática). | [Acessar](./ex02) |
| **03. API Acadêmica** | Construção de um servidor `http` nativo que gerencia rotas e serve arquivos estáticos (HTML, CSS, JS), consumidos via `fetch`. | [Acessar](./ex03) |
| **04. Roteador Institucional** | Roteamento com `http` avaliando `req.url` para rotas específicas (`/fatec`, `/fecap`) e envio de códigos de status (200, 404). | [Acessar](./ex04) |

## 🚀 Como Executar o Projeto

### Pré-requisitos

*   [Node.js](https://nodejs.org/) instalado na máquina.
*   Git para clonar o repositório.

### Passo a Passo


**1. Clone este repositório**
  ```bash
  $ git clone [https://github.com/yasminandrade8/Projeto4-DWIII.git](https://github.com/yasminandrade8/Projeto4-DWIII.git)
  ```
**2. Navegue até a pasta raiz do projeto**
  ```bash
  $ cd Projeto4-DWIII
  ```
**3. Para executar os exercícios, acesse a pasta correspondente e rode o comando:**

Exercício 01
  ```bash
  $cd ex01$ node index.js
  ```
Exercício 02
  ```bash
  $cd ../ex02$ npm start
  ```
Exercício 03
  ```bash
  $cd ../ex03$ node app.js
  ```
Exercício 04
  ```bash
  $cd ../ex04$ node app_2.js
  ```
